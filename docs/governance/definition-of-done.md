# Definition of Done (DoD)

Une user story est terminee uniquement si:
- [ ] Regles metier implementees dans le domaine (pas dans adaptateurs)
- [ ] Tests unitaires + integration + e2e verts
- [ ] Contrat OpenAPI mis a jour
- [ ] Migration base ajoutee si schema modifie
- [ ] Logs et audit ajoutes pour actions sensibles
- [ ] Verification securite (auth + center scope) validee
- [ ] Documentation technique et fonctionnelle mise a jour
- [ ] Revue de code approuvee
